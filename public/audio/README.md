# Voice Recording and Ambient Music

To include your own personal voice recording:
1. Place an MP3 file here named `personal-message.mp3`
2. Open `src/data/storyConfig.js`
3. Set `voiceMessage.enabled: true`

To include custom background music:
1. Place an MP3 file named `background-music.mp3` here
2. By default, the application uses gentle acoustic Web Audio synthesis so it plays beautifully even before an MP3 is provided!
